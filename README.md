# Underscore Protocol: Your Money Never Sleeps

Underscore is a Base-native protocol for AI-managed vaults and agentic wallets. It gives applications, agents, and users a money layer where funds can earn, move, and pay inside onchain rules.

One protocol. Two products.

This is the protocol layer behind agentic finance products built on Underscore, such as Hightop: humans use the app, agents use the API, and Underscore enforces the money movement rules onchain.

## Earn vaults

Earn Vaults put idle assets to work through ERC-4626 vaults managed by AI agents and onchain rules.

- **Core Vaults:** AI-managed passive yield routed across approved DeFi venues.
- **Amplified Vaults:** AI-managed Earn Vault shares with a Ripe-powered second yield layer.

Learn more in the [Earn Vaults docs](https://docs.underscore.finance/earn-vaults/vaults). Live vault addresses and configuration are maintained in the [Params Explorer](https://params.underscore.finance/vaults).

## Programmable wallets

Programmable Wallets are money for agents. AI agents, applications, and trusted operators can pay, rebalance, and move funds within permissions the user controls onchain.

Execution rights, not custody. No private keys. No unrestricted access.

- **[Managers](https://docs.underscore.finance/programmable-wallets/managers):** Delegate execution rights to agents or operators with revocable onchain limits.
- **[Payees](https://docs.underscore.finance/programmable-wallets/payees):** Allow approved recipients to pull funds within configured caps and rules.
- **[Digital Cheques](https://docs.underscore.finance/programmable-wallets/cheques):** Issue one-off payments with optional review and cancellation windows.
- **[Whitelist](https://docs.underscore.finance/programmable-wallets/whitelist):** Allow instant transfers to trusted addresses.

Learn more in the [Programmable Wallets docs](https://docs.underscore.finance/programmable-wallets/user-wallet).

## Security and responsible disclosure

Found a vulnerability? Please report it privately.

- **Email:** underscore_team@proton.me (include "SECURITY" in the subject)
- **Include:** Description, severity, steps to reproduce, affected contracts
- **Do not:** Exploit funds or disclose publicly before we confirm a fix

We acknowledge reports quickly and may offer RIPE token rewards for qualifying disclosures.
