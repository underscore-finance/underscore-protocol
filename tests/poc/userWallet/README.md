# User Wallet Proof-of-Concept Tests

These tests exercise the paused user-wallet proof of concept in
[`contracts/poc/userWallet/`](../../../contracts/poc/userWallet/). They preserve
the experiment's security, lifecycle, compatibility, and gas evidence.

They are not the Wallet v3 production test suite. New Wallet v3 tests belong in
[`tests/walletsV3/`](../../walletsV3/).
