# Wallet v3 Contracts

This directory is reserved for new Wallet v3 implementation work based on the
owner-selected architecture in
[`docs/wallets-v3/`](../../docs/wallets-v3/README.md).

The earlier proof-of-concept contracts are archived separately in
[`contracts/poc/userWallet/`](../poc/userWallet/). Nothing in that PoC directory
is promoted into this directory by implication.

The architecture documents do not themselves authorize contract
implementation, deployment, migration, or live transactions.
