AuthorityHISTORICAL POC LEARNING ARTIFACT · POC ON HOLD · NOT THE GOVERNING ARCHITECTURE

One permanent address holds the money. Everything else must pass through the airlock.

UserWalletV3 is a non-upgradeable vault: no proxy, no delegatecall, no generic executor. Features live in replaceable side-contracts, but none of them can touch funds directly. Every action runs as a session — a one-shot airlock that opens with an explicit, policy-approved request, admits exactly one economic effect, verifies the effect matched the request, and seals itself before the transaction ends.

1 · Custody is permanent

UserWalletV3 owns all tokens, debt positions, and vault shares — keyed to its address forever. Upgrades replace the parts around it; balances and positions never migrate.

2 · Policy is replaceable

ConfigV3 is the rulebook: who may act, which recipients, tokens, actions, and caps. It holds no funds, so a broken Config is swapped by the owner in one call — money never moves.

3 · Features are extenders

Extenders (yield, debt, payments) translate typed calls into session requests. They hold no funds and no standing authority — each action needs a fresh session the Config approves.

4 · Promises are reservations

A payment commitment doesn't send money — it reserves it inside the wallet. Reserved value is invisible to every other spend path until the exact authorized pull or settlement.
